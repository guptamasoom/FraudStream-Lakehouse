# Dashboard Guide

The dashboard is built with Plotly Dash and reads Gold tables from `GOLD_DATA_PATH`.

## Start

```bash
python -m fraudstream.dashboard.app
```

Default URL:

```text
http://localhost:8060
```

## Views

| Section | Purpose |
|---|---|
| KPI cards | Total transactions, high-risk count, total amount, average risk score. |
| Risk analytics | Transaction volume, high-risk trend, rule trigger volume, merchant hotspots. |
| Realtime alerts | Highest-priority suspicious transactions. |
| Customer Risk 360 | Customer-level activity and risk profile. |
| Data quality scorecard | Quality check results by stream and rule. |

## Data Source

The dashboard expects Gold parquet tables generated by:

```bash
bash scripts/run_local_pipeline.sh
```

To use a different path:

```bash
GOLD_DATA_PATH=/path/to/gold python -m fraudstream.dashboard.app
```
